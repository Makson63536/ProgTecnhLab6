Все файлы находятся рядом:

- `hello.py` — среднее № 6: FastAPI «Hello».
- `hello_parameter.py` — среднее № 8: FastAPI принимает параметр.
- `greeting_form.py` — среднее № 2: форма с именем и приветствием на Flask.
- `file_upload.py` — повышенное № 4: загрузка файла через форму на Flask.
- `notes_api.py` и `test_notes_api.py` — повышенное № 10: API заметок и его тестирование с pytest.
- `requirements.txt` — зависимости.

Нужен Python 3.10 или новее. В терминале перейдите в папку, куда распакованы файлы, и установите зависимости:

```bash
python -m venv .venv
```

Активируйте окружение: Windows — `.venv\Scripts\activate`, macOS/Linux — `source .venv/bin/activate`. Затем:

```bash
python -m pip install -r requirements.txt
```

## Запуск заданий

Запускайте одно приложение за раз. Для остановки нажмите Ctrl+C.

**FastAPI «Hello»:**

```bash
python -m uvicorn hello:app --port 8000
```

Откройте http://127.0.0.1:8000/ .

**FastAPI с параметром:**

```bash
python -m uvicorn hello_parameter:app --port 8000
```

Откройте http://127.0.0.1:8000/hello?name=Anna или используйте документацию http://127.0.0.1:8000/docs . Если имя не передано или пустое, возвращается ошибка 422.

**Форма приветствия:**

```bash
python greeting_form.py
```

Откройте http://127.0.0.1:5000/ и введите имя.

**Загрузка файла:**

```bash
python file_upload.py
```

Откройте http://127.0.0.1:5000/ и выберите файл. Разрешены TXT, PDF, PNG, JPG и JPEG; максимальный размер запроса — 5 МБ. При первой загрузке автоматически создаётся папка `uploads`, где файлы сохраняются под случайными именами. Проверяется только расширение, не содержимое; пример предназначен для локального запуска.

**Тестирование API:**

```bash
python -m pytest -v test_notes_api.py
```

Проверяются создание, получение и удаление заметок, а также ошибки. Для ручной проверки API:

```bash
python -m uvicorn notes_api:app --port 8000
```

Документация: http://127.0.0.1:8000/docs . Заметки хранятся в памяти и исчезают после остановки сервера.
